# ideographe.fr website

## About
This is the ideographe.fr website source tree repository, Welcome!

## Astro Framework
This project uses the [Astro](https://astro.build/) framework.

### Features
- design principles:
    - [x] a simple base layout with semantic markup
    - [x] designed with fully decoupled html from styling
    - [x] easy multi language support setup
    - [x] accessibility in mind
    - [x] can use .md or .mdx files for content writing
    - [x] scss support for styling
- seo friendly:
    - [x] meta tags generation from frontMatter
    - [x] favicons generation from a single svg icon
    - [ ] sitemap generation
    - [ ] robots.txt generation
- customs Astro components included:
    - [x] a responsive navbar
- comes with an scss framework:
    - [x] modern css reset
    - [x] responsive column based grid system
    - [x] responsive fluid typography system (based on Utopia)
    - [ ] responsive fluid space
    - [ ] custom fonts-face helpers
    - [x] mixin for css only responsive navbar
    - [ ] mixin for css only image slider
- others:
    - [ ] a javascript css grid viewer available in dev mode server
    - [x] a *frontMatter vsCode plugin* integration
    - [x] typescript strict hinting config
    - [x] nodejs type definitions imported
    - [x] repository comes with a *pre-commit* configuration
